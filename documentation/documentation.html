Festivo — Party Supplies & Decoration Store

A complete, production-ready HTML template for party supplies, event decorations, balloon stores, and celebration businesses.

Introduction

Festivo is a premium, multipurpose HTML template designed specifically for party supplies stores, event decoration services, balloon shops, and celebration businesses.

Built with modern web standards, Festivo offers a complete frontend solution with over 40 pages, responsive layouts, dark mode support, RTL compatibility, and comprehensive admin dashboards.

Premium Design

Modern, festive UI with custom color system and beautiful typography.

Fully Responsive

Mobile-first design tested across all devices and screen sizes.

Dark Mode

Complete dark mode with localStorage persistence.

RTL Support

Full right-to-left language support for Arabic, Hebrew, etc.

Clean Code

Semantic HTML5, modular CSS, and vanilla JavaScript.

Admin Dashboard

Complete admin panel with charts, tables, and management tools.

Getting Started

1. Extract Files

Extract the template ZIP file to your desired location.

2. Open in Browser

Navigate to the template folder and open index.html in your browser to view the homepage.

💡 Local Development

For best results, use a local development server. You can use tools like:

  • VS Code Live Server extension
  • Python: python -m http.server 8000
  • Node.js: npx http-server

3. Customize

Edit the CSS variables in assets/css/style.css to match your brand colors, or modify the HTML content directly in each page.

4. Deploy

Upload all files to your web hosting provider via FTP, or deploy to platforms like Netlify, Vercel, or GitHub Pages.

Customization

Changing Colors

Edit the CSS custom properties in assets/css/style.css:

:root { /* Brand Colors */ --primary: #e8384f; /* Main brand color */ --primary-dark: #c42d42; --primary-light: #fde8eb; --secondary: #f59e0b; /* Accent color */ --accent: #8b5cf6; /* Third accent */ --dark: #0f172a; /* Dark backgrounds */ }

Changing Fonts

Replace the Google Fonts import in the <head> section:

<link href="https://fonts.googleapis.com/css2?family=Your+Font&display=swap">

Then update the font variables in CSS:

:root { --font-sans: 'Your Sans Font', system-ui, sans-serif; --font-serif: 'Your Serif Font', Georgia, serif; }

Changing Logo

Replace the logo icon and text in the header:

<a href="index.html" class="site-logo"> <div class="logo-icon"><img src="assets/images/logo.png" alt="Logo"></div> <span class="logo-text">Your Brand</span> </a>
⚠️ Important

After changing colors or fonts, test across all pages including dark mode and RTL layouts to ensure consistency.

  • Heading Font: Playfair Display (elegant, serif)
  • Base Size: 16px (1rem)
  • Line Height: 1.65 for body text

Spacing Scale

Festivo uses a consistent spacing scale based on 0.25rem (4px) increments:

  • var(--space-1) → 0.25rem (4px)
  • var(--space-2) → 0.5rem (8px)
  • var(--space-4) → 1rem (16px)
  • var(--space-6) → 1.5rem (24px)
  • var(--space-8) → 2rem (32px)
  • var(--space-12) → 3rem (48px)

Cart API

The cart is managed via cart.js and stored in localStorage:

// Add to cart addToCart({ id: 'p1', name: 'Balloon Garland Kit', price: 649, qty: 1, img: 'path/to/image.jpg' }); // Get cart const cart = getCart(); // Update quantity updateCartItem('p1', 3); // Remove from cart removeFromCart('p1'); // Clear cart clearCart();

Toast Notifications

// Show toast showToast('success', 'Success!', 'Product added to cart.'); // Types: success, error, info, warning showToast('error', 'Error', 'Something went wrong.');

Form Validation

Use data-validate attributes:

<input type="text" name="name" data-validate="required|min:2" data-label="Full Name" > <input type="email" name="email" data-validate="required|email" > <input type="password" name="password" data-validate="required|min:8" >

Deployment

Static Hosting (Recommended)

Festivo is a static HTML template and can be deployed to any web hosting:

Netlify

  1. Create a free account at netlify.com
  2. Drag and drop your template folder
  3. Your site is live instantly!

GitHub Pages

  1. Create a GitHub repository
  2. Push your template files
  3. Enable GitHub Pages in repository settings
  4. Your site will be live at username.github.io/repo-name

Traditional Hosting (cPanel)

  1. Upload all files via FTP to public_html
  2. Ensure file permissions are set correctly (644 for files, 755 for directories)
  3. Your site will be live at your domain
✅ Pre-deployment Checklist
  • Update meta tags (title, description) on all pages
  • Replace logo and favicon
  • Update contact information (email, phone)
  • Test all forms and links
  • Optimize images for web
  • Test responsive layouts
  • Verify dark mode works

Backend Integration

To connect Festivo to a backend:

  • Replace localStorage cart with API calls
  • Connect forms to your backend endpoints
  • Replace static product data with database queries
  • Implement real authentication
  • Add payment gateway integration

The template is designed to make backend integration straightforward. Form IDs, data attributes, and JavaScript functions are clearly documented.
